# Kbuild System Specification

Replace CMake-based build system with pure Makefile using Linux kernel Kbuild patterns.

## Requirements Summary

| Requirement | Choice |
|-------------|--------|
| Build system style | Full Kbuild (recursive Makefiles, Kconfig, obj-y, dependency tracking) |
| Configuration | Kconfig menus (menuconfig) |
| CMake fate | Keep as alternative |
| Kconfig tooling | Git submodule (kconfig-frontends) |
| Frontends | menuconfig only (ncurses) |
| Dependency tracking | GCC -MD/-MP |
| Output layout | Out-of-tree (O=) |
| Makefile hierarchy | Per-directory Kbuild files |
| Verbosity | V=0/1 like Linux kernel |
| Config options | Full control (targets + features + per-module) |
| Presets | defconfig, allnoconfig, allyesconfig, testconfig, releaseconfig |
| Test runner | Both (individual + aggregate) |
| Cross-compile | CROSS_COMPILE= prefix support |
| Benchmarks | Submodule Google Benchmark |
| Install | Headers only (PREFIX/include/cpl/) |
| Help target | Comprehensive, categorized |
| Scripts location | scripts/ (follow Linux kernel structure from ~/nvme-qos-linux) |
| Clean hierarchy | make clean, make distclean, make mrproper |

## Reference Implementation

## Kconfig Options

### Top-Level (Kconfig)

```kconfig
mainmenu "CPL Competitive Programming Library Configuration"

config CPL_VERSION
    string
    default "1.0.0"

menu "Build Targets"
    source "tests/Kconfig"
    source "benchmarks/Kconfig"
    source "tools/Kconfig"
endmenu

menu "Compiler Options"
    config CC_OPTIMIZE_FOR_PERFORMANCE
        bool "Optimize for performance (-O2)"
        default y

    config CC_OPTIMIZE_FOR_SIZE
        bool "Optimize for size (-Os)"

    config DEBUG_INFO
        bool "Include debug information (-g)"
        default y

    config ASAN
        bool "Enable AddressSanitizer"
        depends on !RELEASE

    config UBSAN
        bool "Enable UndefinedBehaviorSanitizer"
        depends on !RELEASE

    config RELEASE
        bool "Release build (strip debug, max optimization)"
endmenu

menu "Library Modules"
    source "cpl/Kconfig"
endmenu
```

## Makefile Targets

### Primary Targets

| Target | Description |
|--------|-------------|
| `all` | Build library and enabled targets |
| `cpl` | Build library only |
| `tests` | Build all enabled tests |
| `benchmarks` | Build all enabled benchmarks |
| `tools` | Build all enabled tools |

### Configuration Targets

| Target | Description |
|--------|-------------|
| `menuconfig` | Interactive ncurses configuration |
| `defconfig` | Load default configuration |
| `testconfig` | Load test-focused configuration |
| `releaseconfig` | Load release configuration |
| `allnoconfig` | Disable all optional features |
| `allyesconfig` | Enable all features |
| `oldconfig` | Update config, prompting for new options |
| `savedefconfig` | Save current config as defconfig |

### Test Targets

| Target | Description |
|--------|-------------|
| `test` | Build and run all enabled tests |
| `test-disjoint_set` | Run specific test |
| `test-kruskal_mst` | Run specific test |
| `test-<name>` | Pattern for all tests |

### Cleaning Targets

| Target | Description |
|--------|-------------|
| `clean` | Remove object files and binaries |
| `distclean` | clean + remove .config and generated files |
| `mrproper` | distclean + remove editor backups, tags |

### Utility Targets

| Target | Description |
|--------|-------------|
| `help` | Show all targets with descriptions |
| `install` | Install headers to PREFIX/include/cpl/ |
| `format` | Run clang-format on sources |

## Build Variables

### User-Configurable

| Variable | Default | Description |
|----------|---------|-------------|
| `V` | 0 | Verbosity (0=quiet, 1=verbose) |
| `O` | (in-tree) | Output directory for out-of-tree builds |
| `CROSS_COMPILE` | (empty) | Cross-compiler prefix (e.g., `aarch64-linux-gnu-`) |
| `CXX` | g++ | C++ compiler |
| `AR` | ar | Archiver |
| `PREFIX` | /usr/local | Installation prefix |
| `DESTDIR` | (empty) | Staging directory for packaging |

### Internal (Exported)

| Variable | Description |
|----------|-------------|
| `srctree` | Absolute path to source tree |
| `objtree` | Absolute path to output tree |
| `KBUILD_VERBOSE` | Internal verbosity flag |
| `quiet` | "quiet_" or "" based on verbosity |
| `Q` | "@" or "" based on verbosity |

## Example Kbuild Files

### cpl/Kbuild

```makefile
# Core library objects
obj-y += src/

# Conditional objects based on Kconfig
obj-$(CONFIG_CONTAINER) += container.o
obj-$(CONFIG_TREE) += tree.o
obj-$(CONFIG_MATRIX) += matrix.o
obj-$(CONFIG_MOD) += mod.o
```

### tests/cpl/disjoint_set/Kbuild

```makefile
# Test executable
test-$(CONFIG_TEST_DISJOINT_SET) += disjoint_set_test

disjoint_set_test-objs := test.o
```

## Verbosity Example

```
# V=0 (default, quiet)
$ make
  CXX     cpl/src/output_empty_matrix.o
  AR      cpl/built-in.a
  CXX     tests/cpl/disjoint_set/test.o
  LD      tests/cpl/disjoint_set/disjoint_set_test

# V=1 (verbose)
$ make V=1
g++ -std=c++20 -I./cpl/inc -MD -MP -c -o cpl/src/output_empty_matrix.o cpl/src/output_empty_matrix.cpp
ar rcs cpl/built-in.a cpl/src/output_empty_matrix.o
g++ -std=c++20 -I./cpl/inc -MD -MP -c -o tests/cpl/disjoint_set/test.o tests/cpl/disjoint_set/test.cpp
g++ -o tests/cpl/disjoint_set/disjoint_set_test tests/cpl/disjoint_set/test.o cpl/built-in.a
```

## Out-of-Tree Build Example

```bash
# Create output directory
mkdir build

# Configure and build out-of-tree
make O=build menuconfig
make O=build -j$(nproc)
make O=build test

# Source tree remains clean
ls *.o  # No object files in source
```

## Dependencies

- GNU Make >= 4.0
- GCC or Clang (C++20 support)
- ncurses-dev (for menuconfig)
- flex, bison (for kconfig build)
